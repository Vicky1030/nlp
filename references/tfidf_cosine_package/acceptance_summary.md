# 本轮验收摘要

本轮在包外D盘工作区使用含中文和空格路径的新虚拟环境安装锁定依赖，并从其他工作目录验证了CLI和Python接口。CLI输出4316条预测和相似度；ID、文本、标签和预测与正式结果完全一致，相似度按 `rtol=1e-12, atol=1e-12` 对齐，最大绝对差异为0；固定配置为 `char_1_2`、0.28、`>=`。

接口回归通过：列表、元组和生成器输入成功；空输入返回空列表且不调用 `transform`；单字符串项、长度错误、非字符串和空白句子均按索引拒绝。全量Python接口与CLI一致，修改临时输入标签不影响推理。重复使用已有输出目录以非零退出拒绝且原输出哈希不变。模型与metadata保持原SHA-256，包内文件运行前后未变化。虚拟环境、缓存、测试输入、结果和完整日志均在包外；本摘要不替代原实验日志。
