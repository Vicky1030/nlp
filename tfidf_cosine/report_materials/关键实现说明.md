# 关键实现说明

- 训练阶段从 train 两列句子拟合三个 TF-IDF；validation 通过对应行稀疏向量计算余弦，不建立全量两两相似度矩阵。
- `row_cosine` 对对应行做稀疏点积，并对零向量和浮点边界进行处理；阶段脚本会检查分数范围和缓存分数一致性。
- `tfidf_common.py` 提供可导入的词级分词函数；stage3 从冻结配置解析相对模型路径并用 joblib 重新加载向量器。
- 统一入口和三个阶段入口在写入前列出目标并拒绝已存在的目标；绘图和九例证据脚本也拒绝覆盖。
- 阶段报告包含新 Python 进程 reload 检查；九例证据脚本另行 transform 固定案例，不执行 fit，并核对共同特征贡献和输入哈希。
- 内部训练集的句子用于拟合词表和 IDF，本方法不使用训练标签学习分类器。内部验证集标签用于表示方式和阈值选择；最终评估集标签仅用于固定配置后的评分与错误分析。标签不进入句子向量转换或相似度计算。
- 数据准备阶段使用标签进行分层划分；该用途与 TF-IDF 拟合及相似度计算分开。
- 流程图是方法设计示意，不是实验数据图；evaluation 没有反向连接到参数选择。
