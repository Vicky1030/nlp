# NF4 Few-shot：63% 准确率门槛探索

## 实验边界

- 固定 Qwen3-1.7B、NF4 double quantization、非思考、greedy、max_new_tokens=8、seed=42；无 system prompt。
- 训练集仅用于示例选择；筛选使用固定分层验证子集 480 条，最终确认使用完整 validation 3,433 条。evaluation 未读取、未用于调参。
- 目标：完整验证集 Accuracy≥63%，在达标候选中优先正类 F1，再看正类 Recall。63% 只是本轮门槛，并非高准确率；全判负类准确率约69.21%，但正类 F1/Recall 均为0。
- 初筛宽限至61%，防止因子集波动过早排除候选；初筛达标不等于最终达标。
- 本轮完成16种新配置的480条初筛；选择达初筛宽限且正类F1最高的两组 last_plain、last_unavailable_condition 做完整验证。另一组准确率达标的 last_fresh_reverse 初筛正类Recall仅18.24%，未追加全量。
- 无效输出计错，不从准确率或真实类别召回率的分母删除。逐条核验 ID、原句、标签、示例 ID 和提示词哈希。
- 此验证集已被反复用于调参，结果属于开发结果；选定方案后仍需一次未参与选型的最终评估。

## 选择结论

在本报告已完成且准确率≥63%的 Few-shot 中，正类 F1 最高的是 **旧 Few-shot：fixed2_last_exact**。

不能预设 Few-shot 一定比 Zero-shot 好，也不能只凭高 Recall 认定改善。示例顺序、示例内容和任务表述都可能改变模型的判别倾向；仅改变一项的对比才适合分析该因素。这里不把未经控制的差异解释为因果。

完整开发期预测保留在原实验工作区；本上传包保留冻结 evaluation 逐条预测、最终配置和提示词，分别位于 `outputs/` 和 `results/`。

## 选定提示词

```text
参考示例：
句子1：如何增加？蚂蚁借呗额度
句子2：蚂蚁借呗要怎么样才能提升额度
答案：1

句子1：花呗自动还款什么时候扣除
句子2：花呗自动还款在哪里扣
答案：0

判断两个句子的核心意思是否相同。核心意思相同输出1，意思不同输出0。
句子1：{sentence1}
句子2：{sentence2}
只输出0或1，不要解释。
```

示例均来自 train，ID 按实际出现顺序为：[118, 18614]。
